Everything in one place

Ghostream is a browser first, and a download manager built right into it.

◎

Built-in browser

Open any site in tabs, with bookmarks, private tabs and a fast omnibox for links and search.

↓

Video and file saving

Save videos from supported sites in the quality you pick, or any file from a direct link. Downloads keep going in the background.

⌁

Torrents

Open a magnet link or a .torrent file and download it, with progress in the notification bar.

⊘

Ad blocker

Blocks ads and trackers in the browser using well-known open filter lists.

▦

Sorted folders

Files land in folders for Videos, Music, Documents, Torrents and more, so nothing ends up in a pile.

↗

Share to Ghostream

Tap Share on a link in any app and send it straight to Ghostream.

Get started in 3 steps

About a minute, and no account to create.

  1. Download the APK from the button below and open it.
  2. Allow installs from your browser when Android asks, then tap Install.
  3. Open Ghostream, allow notifications, and start browsing.
