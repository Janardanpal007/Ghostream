05 / GOOD TO KNOW

A few things
you might ask.

Is Ghostream really free?+

Yes. Ghostream is free, open-source software under the GNU GPL v3 license, with no subscription and no account. Ghostream Turbo is an optional one-time upgrade for 2K/4K YouTube and faster downloads; everything else stays free.

How does Ghostream Turbo work?+

Pay once by UPI, send the short form with your transaction ID, and you get a personal 10-character key by email. Copy it and tap Paste key in Settings › Ghostream Turbo. Activating needs internet once; after that Turbo works offline and stays on when you update the app. Please don’t share it: shared keys are switched off.

Which APK should I download?+

Choose ARM64 for most modern 64-bit Android phones. Choose Universal if you don’t know your device’s architecture; it includes all supported architectures in a larger file. Your device must run Android 8.0 or above.

What can I download?+

Ghostream supports file downloads, videos from supported websites, magnet links, and .torrent files. Website support can change. Download only content you have permission to save.

What do the privacy tools do?+

Ghostream offers ad and tracker filter lists, per-site shields, HTTPS upgrades, cookie controls, private tabs, and tracking-tag removal. These tools give you more control; they don’t make your browsing anonymous.

Is the 3D phone running the actual app?+

The explorer shows real screenshots from the Ghostream repository in an interactive 3D frame. Switch features to see each screen, drag horizontally or use the angle slider to rotate, and tap the phone to enlarge the screenshot. To use Ghostream, install the Android APK.

Where can I report a problem or inspect the code?+

Visit the official GitHub repository to read the source, or open an issue with details about your device and the problem.
